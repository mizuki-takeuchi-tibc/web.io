ChatGPT Work 実践準備

Workは、PCにインストールして使うのがおすすめ。

Webでも使えるWorkですが、研修ではPC版がおすすめです。 PC内のExcelやPowerPointなどのファイルを使って、実際の仕事に近い作業を体験できます。

今日のポイント

ChatGPT Workには、大きく分けて クラウドで使うWorkと、 PCにインストールして使うWorkがあります。

無料プランの研修では、
PC内のファイルを使うWork
から始めるのが現実的です。

Google DriveやGmailなどの外部アプリ連携は、 プラン・地域・Workspace設定によって利用できるかどうかが変わります。 無料プランでは表示されない、または接続できない場合があります。

そのため研修では、まず PCに保存したExcelやPowerPointをWorkに渡して使う 方法を中心にします。

※ 利用できる機能は、プラン・地域・アプリのバージョン・組織設定・段階的な提供状況によって変わる場合があります。

Workには2つの使い方がある

☁️
Web / クラウド

クラウドで使うWork

ChatGPTのWeb版などから使うWorkです。 クラウド上で作業を進められます。

  • Webブラウザから使える
  • アップロードしたファイルを使える場合がある
  • 接続アプリを使える場合がある
  • 外部アプリ連携はプランや設定に左右される
💻
Mac / Windows

PCにインストールして使うWork

ChatGPTデスクトップアプリで使うWorkです。 研修では、PC内のExcelやPowerPointを渡して使う方法がわかりやすいです。

  • PC内のファイルを使った実践がしやすい
  • Excel、CSV、PDF、PowerPointなどを扱いやすい
  • 無料プランでも一部を試せる場合がある
  • Gmail連携なしでも、メール文面作成まではできる

無料プランで注意すること

ChatGPTデスクトップアプリをインストールしても、 無料プランではGoogle DriveやGmailなどの外部アプリ連携が使えない場合があります。

つまり、 「Workを少し試せる」ことと、 「Google DriveやGmailを接続できる」こと は別です。

機能 無料プランでの考え方 研修での扱い
Workを使う 一部利用できる場合がある PCに保存したファイルで実演する
Excelファイルを読む ファイル添付やPC内ファイルとして扱える場合がある サンプルExcelで実演する
Google Drive連携 無料プランでは使えない、または表示されない場合がある 本編では前提にしない
Gmail連携 無料プランでは使えない、または表示されない場合がある メール文面だけ作り、送信は手動にする

研修では、PC内ファイルを使うのが安全

参加者全員が同じように体験しやすいように、 研修ではGoogle DriveやGmail連携を前提にせず、 PCに保存したサンプルファイル を使うのがおすすめです。

  • 出席データのExcelをWorkに渡す
  • 出席率が低い学生を抽出する
  • 学生向けの連絡文を作る
  • Gmailには手動でコピーする
  • 最後に人間が確認して送信する

まずはデスクトップアプリを入れてみよう

ChatGPTのデスクトップアプリは、MacとWindowsで利用できます。 研修では、Web版ではなくデスクトップアプリでWorkを開き、 PC内のファイルを使った作業を体験します。

無料Work研修でできること

📊

Excelを読む

出席データ、成績表、アンケート結果などをWorkに読み込ませて、 集計・抽出・要約をしてもらえます。

📝

文面を作る

Gmail連携が使えなくても、 メール本文、案内文、報告文、チェックリストなどは作れます。

📎

資料を作る

PowerPointのテンプレートファイルや過去資料を渡して、 スライド構成や発表者メモを作ることができます。

GPT-6の3つのモデル：Astra・Sol・Luna

WorkやCodexでは、GPT-6系のモデルを選べる場合があります。 初心者向けには、次のようなイメージで理解すると十分です。

最高性能

GPT-6 Astra

もっとも高性能なモデルです。 難しい判断、複雑な仕事、品質を重視した作業に向いています。

イメージ：
重要な仕事で使う上級アシスタント。

バランス型

GPT-6 Sol

高い能力とコストのバランスがよいモデルです。 調査、資料作成、文章作成など幅広い仕事に向いています。

イメージ：
普段の実務で使いやすい主力モデル。

軽量・低コスト

GPT-6 Luna

軽めの作業、下書き、確認、簡単な整理に向いたモデルです。

イメージ：
気軽に試せるアシスタント。

API料金で見るモデルの重さ

以下はOpenAI APIの料金です。 ChatGPTアプリ内の月額プランやWorkの利用枠とは別物ですが、 モデルごとのコスト感を理解する参考になります。

モデル 入力料金 出力料金 ざっくりした見方
GPT-6 Astra $10 / 100万トークン $50 / 100万トークン 高性能だが高コスト。重要な仕事向け。
GPT-6 Sol $2 / 100万トークン $10 / 100万トークン Astraより安く、実務で使いやすいバランス型。
GPT-6 Luna $0.10 / 100万トークン $0.50 / 100万トークン 低コスト。軽い作業や試行錯誤向け。

※ 上記は標準・短いコンテキストのAPI料金です。ChatGPTアプリ内の料金・利用枠とは別です。

初心者向けの結論

  • 無料プランの研修では、Google Drive / Gmail連携を前提にしない。
  • PCに保存したExcelやPowerPointをWorkに渡す。
  • メール送信は自動化せず、文面作成までにする。
  • Gmailには人間がコピーして送る。

まずは、外部連携なしでWorkを体験する。

Excelを読む、対象者を抽出する、メール文面を作る。
これだけでも、ChatGPT Workが 「作業を進めるAI」 だと実感できます。
