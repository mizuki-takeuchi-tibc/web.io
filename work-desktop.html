ChatGPT Work 実践準備

Workは、PCにインストールして使うのがおすすめ。

Webやスマホでも使えるWorkですが、本領を発揮するのはデスクトップアプリ。 PC内のファイルやアプリを使って、実際の仕事に近い作業ができます。

今日のポイント

ChatGPT Workには、大きく分けて クラウドで使うWorkと、 PCにインストールして使うWorkがあります。

初心者にこそおすすめしたいのは、
PCにインストールして使うWorkです。

理由はシンプルです。 デスクトップ版のWorkは、許可した範囲で PC内のファイル、フォルダ、アプリ、ブラウザ を使いながら作業できるからです。

※ 利用できる機能は、プラン・地域・アプリのバージョン・組織設定・段階的な提供状況によって変わる場合があります。

Workには2つの使い方がある

☁️
Web / スマホ

クラウドで使うWork

ChatGPTのWeb版やスマホアプリから使うWorkです。 外出先でも始めやすく、クラウド上で作業を進められます。

  • Webやスマホから使える
  • クラウド上で作業する
  • アップロードしたファイルや接続アプリを使える
  • PC内のローカルファイルには直接アクセスしにくい
💻
Mac / Windows

PCにインストールして使うWork

ChatGPTデスクトップアプリで使うWorkです。 PC上のフォルダを開いたり、許可したアプリを使ったりできます。

  • PC内のファイルやフォルダを使える
  • デスクトップアプリやブラウザを使った作業ができる
  • 実際の仕事ファイルをもとに資料作成しやすい
  • 無料プランでも一部を試せる

なぜPC版がおすすめなのか

Workの価値は、ただ質問に答えてもらうことではありません。 すでに自分のPCにあるファイルを使って、 作業を一緒に進めてもらえる ところにあります。

  • WordやPDFの資料を読み込んで、要約を作る
  • ExcelやCSVをもとに、表や分析のたたき台を作る
  • 授業資料をもとに、スライド案や配布資料を作る
  • フォルダ内の複数ファイルを確認して、整理案を出す
  • Webページや簡単なサイトの原稿を作る

つまり、ChatGPTを 「質問する場所」から「一緒に作業する場所」 に変えられます。

まずはデスクトップアプリを入れてみよう

ChatGPTのデスクトップアプリは、MacとWindowsで利用できます。 デスクトップアプリでは、Chat、Work、Codexを使う入り口になります。

ChatGPTアプリをダウンロード

今日のおすすめ：
Web版だけで終わらせず、PCにアプリを入れて Workを開いてみる。

注意：PCの中を勝手に全部見るわけではない

PCで動くWorkは便利ですが、 何でも勝手に見たり操作したりするわけではありません。

  • 使うファイルやフォルダは、ユーザーが許可する必要があります
  • アプリ操作やブラウザ操作にも、権限や承認が必要な場合があります
  • 会社や学校のPCでは、管理者設定で使える機能が制限される場合があります
  • 重要データを使う場合は、組織のルールに従って使いましょう

GPT-6の3つのモデル：Astra・Sol・Luna

WorkやCodexでは、GPT-6系のモデルを選べる場合があります。 初心者向けにいうと、次のようなイメージです。

最高性能

GPT-6 Astra

もっとも高性能なモデルです。 難しい判断、複雑な仕事、品質を重視した作業に向いています。

イメージ：
一番頼れる上級アシスタント。

バランス型

GPT-6 Sol

高い能力とコストのバランスがよいモデルです。 仕事、調査、資料作成、開発など幅広く使いやすいモデルです。

イメージ：
実務で使いやすい主力モデル。

軽量・低コスト

GPT-6 Luna

低コストで使いやすいモデルです。 軽めの作業、下書き、確認、簡単な整理に向いています。

イメージ：
気軽に何度も使えるアシスタント。

API料金で見るモデルの重さ

以下はOpenAI APIの料金です。 ChatGPTの月額プラン料金とは別物ですが、 モデルごとの「重さ」や「コスト感」を理解する参考になります。

モデル 入力料金 出力料金 ざっくりした見方
GPT-6 Astra $10 / 100万トークン $50 / 100万トークン 高性能だが高コスト。重要な仕事向け。
GPT-6 Sol $2 / 100万トークン $10 / 100万トークン Astraより安く、実務で使いやすいバランス型。
GPT-6 Luna $0.10 / 100万トークン $0.50 / 100万トークン かなり低コスト。軽い作業や試行錯誤向け。

※ 上記は標準・短いコンテキストのAPI料金です。ChatGPTアプリ内の月額料金・利用枠とは別です。

初心者向けの結論

  • WorkはPC版がおすすめ。 PC内のファイルを使った実務に近い作業ができるから。
  • 無料でも一部は試せる。 ただし、本格的に使うなら利用枠やモデル制限を確認する。
  • モデルは軽い順に Luna → Sol → Astra。 迷ったら、気軽な作業はLuna、普段の仕事はSol、重要な仕事はAstra。

ChatGPTを、
「質問するAI」から「作業を任せるAI」へ。

このあと実際に、ChatGPTデスクトップアプリでWorkを開き、 ファイルを使った作業を体験してみます。
