AI Agent

AIは「答える道具」から「動く相棒」へ

これまで多くの生成AIは、こちらが質問や依頼を入力すると、 文章、要約、コード、アイデアなどを返してくれる存在でした。

しかし最近は、AIが単に回答するだけではなく、 目的を理解し、複数の作業を進め、必要に応じて確認しながら動く 方向に進んでいます。

従来型のAI

  • 質問すると答える
  • 文章を作る
  • 要約する
  • コードを書く
  • 基本的には一回ごとの依頼で動く

AIエージェント

  • 目的に向かって作業を進める
  • 複数のステップを扱う
  • ツールやファイルと連携する
  • 必要に応じて継続的に作業する
  • 人間の確認を挟みながら進める

今回の研修で扱った「調査して提案書を作る」「フォームを作る」「Webページを作る」「アプリを作る」という流れも、 将来的にはAIエージェントがより自然に進めてくれるようになる可能性があります。

Dots

Dotsとは

Dotsは、OpenAIが発表しているAIエージェントの一種です。 複雑なプロジェクトや日常的なタスクを、継続的に進める存在として紹介されています。

Dotsのイメージ

  • 常にそばにいるアシスタント
  • 作業の続きを覚えている
  • 複数のタスクをまたいで動く
  • 調査、分析、文書作成、開発などを支援する
  • ChatGPTの作業体験をさらにエージェント化したもの

今回の研修に置き換えると

  • 提案書作成の続きを覚えている
  • フォーム作成やWebページ作成につなげる
  • 作業途中の状況を把握する
  • 次にやるべきことを提案する
  • プロジェクト全体を管理する
研修での説明ポイント： Dotsは「一問一答のAI」ではなく、 継続的に仕事を進めるAIエージェント として紹介すると分かりやすいです。

Muse

Museとは

Museは、Metaが提供するパーソナルAIエージェントです。 個人の予定、タスク、ファイル、メッセージなどと連携しながら、日常の作業を支援するAIとして紹介されています。

Museのイメージ

  • 個人用のAIアシスタント
  • 日常のタスクを整理する
  • 予定やメッセージと連携する
  • ファイル整理や作業の補助を行う
  • 無料枠で試しやすい

業務で考えられる使い方

  • 今日やることの整理
  • 打ち合わせ前の準備
  • 資料作成の下準備
  • メールやメモの整理
  • 個人タスクの抜け漏れ防止
ポイント： Museは、難しい開発や業務自動化というより、 まずは日常の作業を手伝うAIエージェントとして紹介すると受講者に伝わりやすいです。

Comparison

DotsとMuseの違い

項目 Dots Muse
提供元 OpenAI Meta
位置づけ ChatGPTの作業体験を発展させた、継続的に仕事を進めるAIエージェント。 個人の予定、タスク、ファイル、メッセージなどを手伝うパーソナルAIエージェント。
向いている使い方 プロジェクト作業、調査、分析、文書作成、開発作業の継続支援。 日常タスク、予定管理、メモ整理、個人作業の補助。
今回の研修との関係 第1章から第6章までのような連続作業を、将来的にまとめて進めるイメージに近い。 研修後に、受講者が自分の日常業務でAIエージェントを試す入口として向いている。
紹介のしやすさ 「仕事を続けて進めるAI」という未来像として紹介しやすい。 無料枠で試しやすく、研修後の一歩として勧めやすい。

どちらが上という話ではありません。 Dotsは「仕事やプロジェクトを継続的に進めるAI」、 Museは「個人の日常タスクを支援するAI」として捉えると分かりやすいです。

Recommendation

最後にMuseを勧める理由

Museは、無料枠で試しやすく、いきなり業務システムを大きく変えなくても、 個人のタスク整理や日常業務の補助から始められるためです。

1. 試しやすい

無料枠があるため、まずは個人で触ってみる入口として紹介しやすいです。

2. 日常業務に近い

予定、タスク、メモ、ファイル整理など、受講者がイメージしやすい作業に使えます。

3. AIエージェントを体験できる

一問一答ではなく、AIに作業を手伝ってもらう感覚を体験しやすいです。

研修の締め方： 「まずはChatGPTで基本を学び、次にAIエージェントを試すならMuseから触ってみる」 という流れで締めると、受講者が次に何をすればよいか分かりやすくなります。

Try Muse

Museで試してみること

研修後にMuseを試すなら、いきなり重要な業務を任せるのではなく、 自分だけで確認できる小さなタスクから始めます。

最初に試しやすいこと

  • 今日やることを整理してもらう
  • 今週の予定を確認してもらう
  • メモをもとにタスクリストを作ってもらう
  • 打ち合わせ前に確認事項を整理してもらう
  • 作業の優先順位を一緒に考えてもらう

慣れてきたら試すこと

  • 資料作成前の構成案を出してもらう
  • メール返信の下書きを考えてもらう
  • ファイルやメモを整理してもらう
  • 定期的な作業の抜け漏れを確認してもらう
  • 目標に対する次の行動を提案してもらう

Museに依頼する例

Museで試す依頼例 
今日やることを整理したいです。
以下のメモをもとに、優先順位をつけたタスクリストにしてください。

# 今日やりたいこと
- 研修資料を確認する
- 参加者リストを整理する
- 上司に進捗を報告する
- メールの返信をする
- 明日の打ち合わせの準備をする

# 出力してほしい形式
1. 今日必ずやること
2. できればやること
3. 明日以降でもよいこと
4. 最初に取りかかるべき作業

最初は、個人情報や機密情報を含まないメモで試してください。 便利さを感じたら、社内ルールに沿って業務利用の範囲を確認します。

Caution

利用時の注意点

AIエージェントは便利ですが、通常のチャットAI以上に、 ファイル、予定、メッセージ、タスクなどと連携する可能性があります。 そのため、利用前に確認すべき点があります。

確認すること

  • どの情報にアクセスできるのか
  • どのアプリと連携しているのか
  • 自動で何を実行できるのか
  • 送信前に人間の確認が入るのか
  • 会社の利用ルールに反していないか

入れない方がよい情報

  • 顧客情報
  • 個人情報
  • 社外秘資料
  • 未公開の経営情報
  • パスワードや認証コード
重要： AIエージェントは「便利だから何でも任せる」のではなく、 何を見せるか、何を任せるか、どこで人間が確認するか を決めて使うことが大切です。

Final Message

最後のメッセージ

今回の研修では、ChatGPTを中心に、生成AIでできることを幅広く体験しました。 文章を作るだけでなく、資料作成、フォーム作成、Webページ作成、アプリ作成、exe化、Web公開まで、 AIを使うことで多くの作業を進められることが分かったと思います。

そして、これからのAIはさらに進みます。 これまでのように「質問に答えるAI」だけでなく、 目的に向かって作業を進める AIエージェント が広がっていきます。

まずは、今回学んだChatGPTの使い方を業務の小さな作業で試してみてください。 その次の一歩として、無料枠で試せるMuseのようなAIエージェントにも触れてみると、 これからの働き方のイメージがさらに広がります。

締めの一言： 生成AIは、使う人の仕事を奪うものではなく、 使う人の可能性を広げる道具です。 まずは安全な範囲で、小さく試すところから始めましょう。
