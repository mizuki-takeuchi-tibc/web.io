Pythonアプリをexeファイルに変換する

この章では、第4章で作成した 「生成AI研修 参加日別リスト作成ツール」 を、Windowsで実行できる exeファイル に変換します。

Pythonファイルのままだと、実行するPCにPython環境が必要です。 exeファイルに変換すると、アプリの形に近づき、ダブルクリックで起動できるようになります。

この章のポイント： 第5章ではコードを書きません。 第4章で作った app.py を、配布しやすいexeファイルに変換する流れを体験します。

Connection

第4章とのつながり

第4章で作ったもの

ChatGPTにPythonコードを書いてもらい、 Googleフォームの回答CSVから参加日別のメンバーリストを作成する app.py を作成しました。

第5章で作るもの

第4章の app.py をもとに、 ダブルクリックで起動できる app.exe を作成します。

今回は、Pythonアプリをexe化する代表的なツールである PyInstaller を使います。

研修では、まず自分のPC上でexeファイルが作成できることを確認します。

Preparation

事前準備

1. Python 3.13

Pythonがインストールされていることを確認します。

Python確認コマンド 
python --version

上記で確認できない場合は、以下も試します。

別の確認コマンド 
py --version

2. 第4章で作成した app.py

第4章で作成した app.py を使います。

exe化する前に、以下のコマンドでアプリが起動することを確認しておきます。

app.py 実行確認 
python app.py

3. サンプルCSV

第4章で使用したサンプルCSVも用意しておきます。

exe化後のアプリでも、CSVを読み込めるか確認します。

4. コマンドプロンプト

PyInstallerのインストールとexe化は、コマンドプロンプトで行います。

app.py を保存したフォルダを開き、アドレスバーに cmd と入力してEnterを押すと、その場所でコマンドプロンプトを開けます。

注意： exe化する前に、必ず app.py が正常に動くことを確認してください。 Pythonファイルの時点でエラーが出ている場合、exe化しても正常には動きません。

Install

PyInstallerをインストールする

まず、Pythonアプリをexeファイルに変換するためのツール PyInstaller をインストールします。

  1. app.py を保存したフォルダを開きます。
  2. フォルダのアドレスバーに cmd と入力してEnterを押します。
  3. コマンドプロンプトが開いたら、以下のコマンドを実行します。
PyInstallerインストールコマンド 
python -m pip install pyinstaller

環境によっては、以下のコマンドを使います。

py コマンドを使う場合 
py -m pip install pyinstaller

しばらく待って、最後に Successfully installed のような表示が出ればインストール完了です。

権限エラーが出た場合

会社PCなどでは、通常のインストールで権限エラーが出る場合があります。 その場合は、以下のコマンドを試します。

ユーザー領域にインストールするコマンド 
python -m pip install --user pyinstaller
会社PCの場合： セキュリティ設定により、Pythonパッケージのインストールやexeファイルの作成が制限されていることがあります。 その場合は、無理に設定を変更せず、社内のIT担当者に確認してください。

Check

PyInstallerが入ったか確認する

インストールが終わったら、PyInstallerが使える状態になっているか確認します。

PyInstaller確認コマンド 
python -m PyInstaller --version

バージョン番号が表示されればOKです。

上記でうまくいかない場合は、以下も試します。

py コマンドで確認 
py -m PyInstaller --version
確認ポイント： この章では pyinstaller コマンドを直接使うよりも、 python -m PyInstaller の形で実行する方が環境差に強いです。

Folder

作業フォルダを確認する

exe化する前に、作業フォルダの中身を確認します。 最低限、以下のようになっていればOKです。

作業フォルダ例 
ai-training-app/
  app.py
  ai-training-application-sample.csv

コマンドプロンプトで現在のフォルダに app.py があるか確認するには、 以下のコマンドを使います。

フォルダ内のファイル確認 
dir
重要： app.py があるフォルダでexe化コマンドを実行してください。 別のフォルダで実行すると、app.py が見つからないというエラーになります。

Build

exeファイルを作成する

いよいよ app.py をexeファイルに変換します。 以下のコマンドを実行してください。

exe化コマンド 
python -m PyInstaller --onefile --windowed app.py

py コマンドを使う環境では、以下を使います。

py コマンドでexe化 
py -m PyInstaller --onefile --windowed app.py

コマンドの意味

python -m PyInstaller

PythonからPyInstallerを実行する、という意味です。

--onefile

できるだけ1つのexeファイルにまとめる指定です。

--windowed

アプリ起動時に黒いコマンド画面を表示しない指定です。

実行すると、しばらく文字が流れます。 最後にエラーが出ずに終了すれば、exeファイルの作成は完了です。

exe化後に作成されるフォルダ

コマンド実行後、作業フォルダ内に以下のようなファイルやフォルダが作成されます。

exe化後のフォルダ例 
ai-training-app/
  app.py
  app.spec
  build/
  dist/
    app.exe
完成したexeファイルはここ： dist フォルダの中にある app.exe が完成品です。

Run EXE

完成したexeファイルを実行する

  1. 作業フォルダの中にある dist フォルダを開きます。
  2. app.exe をダブルクリックします。
  3. アプリ画面が表示されることを確認します。
  4. 「CSVを選択」ボタンからサンプルCSVを読み込みます。
  5. 第1回・第2回・第3回の参加者リストが表示されることを確認します。
  6. 参加者リストをテキストファイルとして保存できるか確認します。
最初の起動は少し時間がかかる場合があります。 特に --onefile で作成したexeは、起動時に内部ファイルを展開するため、 通常のPython実行より少し待つことがあります。

ファイル名を分かりやすくする

完成した app.exe は、必要に応じて名前を変更できます。

ファイル名変更例 
app.exe
↓
生成AI研修_参加日別リスト作成ツール.exe
研修での完成目標： 生成AI研修_参加日別リスト作成ツール.exe をダブルクリックして起動し、CSVを読み込んで参加日別リストを表示できる状態にします。

Troubleshooting

よくあるトラブル

pip install pyinstaller が失敗します

まずインターネット接続を確認してください。 会社PCの場合、外部パッケージのインストールが制限されている可能性があります。 python -m pip install --user pyinstaller も試してください。

python コマンドが認識されません

py --version を試してください。 py でPythonのバージョンが表示される場合は、 py -m pip install pyinstaller や py -m PyInstaller --onefile --windowed app.py を使います。

No module named PyInstaller と表示されます

PyInstallerが正しくインストールされていない可能性があります。 もう一度 python -m pip install pyinstaller を実行してください。 py を使っている環境では py -m pip install pyinstaller を試してください。

app.py が見つからないと表示されます

コマンドプロンプトを開いている場所が違う可能性があります。 dir を実行し、一覧に app.py があるか確認してください。

dist フォルダが見つかりません

exe化コマンドが途中でエラー終了している可能性があります。 コマンドプロンプトに表示されたエラーを確認してください。 分からない場合は、このページの「PyInstallerエラー修正依頼」プロンプトを使ってChatGPTに相談します。

app.exe を起動しても何も起きません

まず --windowed を外してexe化し、エラー内容を確認する方法があります。 以下のコマンドを試してください。

エラー確認用のexe化コマンド 
python -m PyInstaller --onefile app.py

この場合、exe実行時に黒い画面が表示され、エラー内容を確認しやすくなります。

ウイルス対策ソフトに警告されます

自作のexeファイルは、環境によって警告が出る場合があります。 会社PCでは無理に実行せず、IT担当者に確認してください。 研修では、自分で作成したファイルのみを実行し、出所不明のexeファイルは実行しないでください。

exeファイルを他のPCで実行できません

他のPCのセキュリティ設定やWindowsのバージョン、権限によって実行できない場合があります。 社内配布を目的とする場合は、IT担当者に確認してください。

exe化するとファイルサイズが大きくなります

PyInstallerはPython実行に必要なものをまとめるため、ファイルサイズが大きくなることがあります。 これは一般的な挙動です。
