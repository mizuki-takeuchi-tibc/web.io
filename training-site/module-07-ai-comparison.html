Hands-on 07

ここまでの作業は、他のAIならどの機能でできるのか

この章では、第1章から第6章までで体験した作業を、 ChatGPT以外の生成AIで行う場合に、どのサービス・どの機能を使うのかを整理します。

比較するのは、主に以下の3系統です。

Gemini系

Googleの生成AIです。 Google Workspace、Googleドライブ、Gmail、Googleフォーム、Google Apps Scriptとの相性がよいのが特徴です。

Claude系

Anthropicの生成AIです。 長文読解、文章作成、資料構成、コード作成、ArtifactsやClaude Codeを使った開発支援が特徴です。

Copilot系

MicrosoftやGitHubの生成AIです。 Word、Excel、PowerPoint、Outlook、Teams、GitHubとの連携が強いのが特徴です。

この章のポイント： 「どのAIが一番すごいか」ではなく、 自社の環境ややりたい作業に合うAIを選ぶ という視点で整理します。

Summary

まず結論

今回の研修内容を一番まとめて体験しやすいのは

今回のように、調査、資料作成、メール、フォーム作成、Web制作、Pythonコード作成までを 1つの流れで体験するなら、ChatGPTは扱いやすい選択肢です。

特に、ChatGPTのWorkやCodexのように、作業単位で進める機能があると、 研修の流れを作りやすくなります。

ただし、会社の環境によって最適解は変わる

Google Workspace中心の会社ならGemini系、 Microsoft 365中心の会社ならCopilot系、 文章作成や長文整理を重視するならClaude系が有力です。

開発やコード作成を重視する場合は、Claude Code、GitHub Copilot、Gemini Code Assist、Julesなども候補になります。

つまり、今回の研修で学んだ考え方はChatGPT専用ではありません。 「AIに作業を依頼する」「出力を確認する」「必要に応じて修正する」という流れは、 Gemini、Claude、Copilotでも応用できます。

第4章 ChatGPTで参加日別リスト作成アプリを作成 GeminiにPythonコードを書かせる。 実行は自分のPC上のPythonで行う。 ClaudeにPythonコードを書かせる。 長いコードの改善や説明も得意。 Copilot ChatやGitHub CopilotにPythonコード作成を依頼する。
第5章 PyInstallerでexe化 Geminiに手順やエラー対応を相談する。 実行はPCのコマンドプロンプトで行う。 Claudeにエラー文を貼り付けて原因調査や修正手順を相談する。 CopilotやGitHub Copilotにコマンドやトラブル対応を相談する。
第6章 ChatGPTでHTML/CSS/JSを書き、GitHub Pagesで公開 GeminiにHTML/CSS/JSを書かせる。 GitHub Pages公開手順も相談できる。 Claude Artifactsで見た目を確認しながら作る。 HTML/CSS/JSの修正も得意。 GitHub CopilotやCopilot Chatでコード作成・GitHub公開を支援する。

どのAIでも「コードを書いてもらう」「手順を聞く」「エラーを貼って相談する」ことはできます。 違いが出るのは、どの業務ツールと直接つながっているか、どこまで自動で実行できるかです。

Gemini

Gemini系でやるなら

Gemini系は、Google Workspaceを使っている会社と相性がよいです。 Gmail、Googleドライブ、Googleドキュメント、Googleスプレッドシート、Googleフォーム、Google Apps Scriptを使う業務では特に候補になります。

第1章の代替

調査はGemini Deep Research、文書作成はGeminiやGoogleドキュメント、 メール作成はGmailのGemini支援を使う流れが考えられます。

第2章の代替

Googleフォームを作るApps ScriptコードをGeminiに作らせます。 Googleの環境内で完結しやすいので、今回の第2章とは相性がよいです。

第3章の代替

Webページやアプリ開発では、Jules、Gemini Code Assist、Google Antigravityなどが候補になります。 ただし、利用できる機能はプランや提供状況によって異なります。

第4章〜第6章の代替

Pythonコード、PyInstallerの手順、HTML/CSS/JavaScriptコードの作成はGeminiにも依頼できます。 実行や公開は自分のPCやGitHub上で行います。

Gemini系が向いている会社： Google Workspaceを日常的に使っていて、Gmail、Googleドライブ、Googleフォーム、スプレッドシートを中心に業務をしている会社。

Claude

Claude系でやるなら

Claude系は、文章の整理、長文の読み込み、提案書作成、構成作り、コード作成と相性がよいです。 また、Artifactsを使うと作成したHTMLや簡単なWebアプリの見た目を確認しながら作業しやすくなります。

第1章の代替

生成AI研修の必要性の整理、提案書の構成、文章の改善はClaudeに依頼できます。 ただし、メール送信やGoogle Drive保存は、基本的に別途操作が必要です。

第2章の代替

Googleフォーム作成用のApps ScriptコードをClaudeに書かせることはできます。 その後、Google Apps Scriptに貼り付けて実行する流れになります。

第3章の代替

Claude Codeを使えば、Webページやアプリのファイル作成、修正、開発作業を支援できます。 Artifactsを使えば、Webページのたたき台確認もしやすいです。

第4章〜第6章の代替

Pythonコード、エラー修正、HTML/CSS/JavaScript作成はClaudeでも対応しやすい作業です。 特に長いコードの説明や修正方針の整理に向いています。

Claude系が向いている会社： 長文資料、提案書、規程文書、マニュアル、FAQ、文章品質を重視する会社。 また、コードやWebページを対話しながら改善したい場合にも向いています。

Copilot

Copilot系でやるなら

Copilot系は、Microsoft 365やGitHubを使っている会社と相性がよいです。 Word、Excel、PowerPoint、Outlook、Teams、OneDrive、SharePoint、GitHubを中心に業務をしている場合は候補になります。

第1章の代替

調査や情報整理はMicrosoft 365 CopilotのResearcher、 提案書はWord、資料はPowerPoint、メールはOutlookのCopilotを使う流れが考えられます。

第2章の代替

Googleフォームではなく、Microsoft FormsやPower Automate、Copilot Studioを使う方がMicrosoft環境には合いやすいです。 Google Apps Scriptのコード作成自体をCopilotに相談することもできます。

第3章の代替

GitHub CopilotやCopilot coding agentを使えば、リポジトリ上のWebページ作成や修正を支援できます。 GitHub中心で開発する場合に相性がよいです。

第4章〜第6章の代替

PythonコードやHTML/CSS/JavaScriptの作成はGitHub CopilotやCopilot Chatで支援できます。 Excelデータの分析や社内文書化はMicrosoft 365 Copilotとの相性がよいです。

Copilot系が向いている会社： Microsoft 365を中心に業務をしていて、Word、Excel、PowerPoint、Outlook、Teams、SharePoint、GitHubをよく使う会社。

Workflow

目的別の選び方

やりたいこと 向いているAI・機能 理由
調査して提案書を作りたい ChatGPT Work、Gemini Deep Research、Microsoft 365 Copilot Researcher、Claude 情報収集、要約、構成作成、文書化が必要なため。
GoogleフォームやApps Scriptを扱いたい Gemini、ChatGPT、Claude Google環境との相性はGeminiが高い。 ただしApps Scriptコード作成は他AIにも依頼できる。
Word、Excel、PowerPoint、Outlookで使いたい Microsoft 365 Copilot Microsoft 365アプリ内で使えるため、日常業務に組み込みやすい。
Webページやアプリを作りたい ChatGPT Codex、Claude Code、GitHub Copilot、Gemini Code Assist、Jules ファイル作成、コード修正、リポジトリ操作などの支援が必要なため。
HTML/CSS/JavaScriptを書かせたい ChatGPT、Claude、Gemini、GitHub Copilot いずれもコード生成は可能。 ただし、公開やファイル配置は自分で確認する必要がある。
Pythonコードやexe化手順を相談したい ChatGPT、Claude、Gemini、GitHub Copilot コード作成、エラー修正、PyInstaller手順の説明は多くのAIで対応できる。

Training Design

企業向け研修で扱うなら

企業研修では、受講者の会社で普段使っている環境に合わせてAIを選ぶのが重要です。 同じ生成AI研修でも、Google Workspace中心の会社とMicrosoft 365中心の会社では、実践しやすい内容が変わります。

Google Workspace中心

Geminiを軸に、Googleフォーム、Googleスプレッドシート、Google Apps Script、Gmail、Googleドライブを扱う研修が自然です。

Microsoft 365中心

Copilotを軸に、Word、Excel、PowerPoint、Outlook、Teams、OneDrive、SharePointを扱う研修が自然です。

開発・制作寄り

ChatGPT Codex、Claude Code、GitHub Copilot、Gemini Code Assistなどを使い、 Webページや簡単なアプリ作成を扱うと効果的です。

今回の研修の位置づけ： ChatGPTを軸にして、調査、提案書、フォーム、Webページ、PCアプリ、exe化、無料Web公開までを一通り体験しました。 他のAIを使う場合も、同じ考え方で置き換えることができます。

おすすめの伝え方

受講者には、以下のように説明すると分かりやすいです。

今回はChatGPTで一連の流れを体験しましたが、これはChatGPTでしかできないという意味ではありません。 Google Workspaceを使っている会社ならGemini、Microsoft 365を使っている会社ならCopilot、 文章作成やコード改善を重視するならClaudeも候補になります。 大事なのは、AIの名前を覚えることではなく、自分の業務に合わせて 「どのAIに、何を、どこまで任せるか」を考えられるようになることです。

Review

まとめ

この研修で体験したこと

  • AIに調査と提案書作成を依頼する
  • Googleフォームを自動生成する
  • WebページをAIで作成する
  • PythonアプリをAIに作らせる
  • Pythonアプリをexe化する
  • HTMLファイルをGitHub Pagesで公開する
  • 他AIでの置き換え方を知る

実務で大切な考え方

  • AIに任せる作業と人間が確認する作業を分ける
  • 機密情報や個人情報を入力しない
  • 出力された文章やコードを必ず確認する
  • 自社の業務環境に合うAIを選ぶ
  • 小さな業務改善から試す
最終メッセージ： 生成AIは、単に文章を作る道具ではありません。 調査、資料作成、フォーム作成、Web制作、アプリ作成、業務自動化の入口として使えます。 まずは安全な範囲で、小さな作業から試してみましょう。
