# ATELIER BLOOM

オリジナルのキャラクターと3つの描き下ろし背景で楽しむ、メイクアップ＆着せ替えゲームです。

- リップ・アイシャドウ・チーク・ハイライト、それぞれ5色＋クリア、濃さの調整
- 6種類の衣装＋元のベース服、衣装カラー6色、シューズ4種類
- イヤリング・ネックレス・ヘアアクセサリー・バッグ、それぞれ3種類＋なし
- アトリエ・夕暮れのテラス・月夜のサロン
- コーデ保存（12件）・呼び出し・削除、変更の取り消し・やり直し
- 写真ダウンロード（1080×1600 PNG）
- 3つのお題チャレンジとスタンプ
- スマートフォンではプレビューを見ながら操作できます

## 起動

GitHub Pagesで `atelier-bloom/` を開きます。ローカルではリポジトリのルートから次を実行してください。

```sh
python3 -m http.server 8000
```

依存パッケージやAPIキーは不要です。コーデとスタンプはブラウザー内のlocalStorageに保存します。ブラウザーデータを消すと失われるので、大事なコーデは写真でも保存してください。写真ダウンロードは画像を取得するため、HTTP経由での利用を想定しています。

## 画像と描画

4枚のPNGはこのゲーム向けに生成したオリジナル素材です。衣装、メイクの色、アクセサリー、化粧品アイコンはSVGで描画し、キャラクターの上に重ねています。外部画像やフォントのCDNには依存しません。

## 検証

Chromium / Playwrightで全カテゴリ・衣装・カラー・アクセサリー・背景の切り替え、保存と再読み込み、保存名のエスケープ、取り消し／やり直し、実際のPNGダウンロード、チャレンジとスタンプの保持、削除・リセット時の確認、スマートフォンでの操作と横幅を検証しました。
