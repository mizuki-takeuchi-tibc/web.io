HTMLを公開する

GitHubで学習用HTMLをインターネット公開する

作成したHTMLファイルをGitHubに入れて、インターネットで見られるようにします。 ここでは、はじめて使う人向けに、できるだけ簡単な言葉で説明します。

このページでやること

作ったHTMLを、学生が見られるページにする

前のページでは、Notebookで学習用HTMLを作りました。 このページでは、そのHTMLファイルをGitHubに入れて、インターネットで開けるようにします。

GitHubを使うと、HTMLファイルを無料で公開できます。 公開すると、学生にURLを送って見てもらうことができます。

1 HTMLファイル

作った学習用HTMLを用意します。

2 GitHubに入れる

HTML、CSS、画像をGitHubに入れます。

3 公開設定

GitHub Pagesをオンにします。

4 URLで見られる

公開URLを開いて確認します。

最初に知っておく言葉

GitHubには少しむずかしい言葉があります。 このページでは、次のように考えれば大丈夫です。

言葉 かんたんな意味
GitHub HTMLファイルなどを保存して、公開できるサービス
アカウント GitHubを使うための自分の名前とログイン情報
リポジトリ ファイルを入れておく箱
GitHub Pages GitHubに入れたHTMLをWebページとして公開する機能
公開URL 学生に送るWebページのアドレス

作業の流れ

順番 やること 使うもの
1 GitHubアカウントを作る GitHub
2 HTMLを入れる箱を作る GitHubのリポジトリ
3 HTMLファイルを入れる Upload files
4 GitHub Pagesをオンにする Settings
5 公開URLを開いて確認する ブラウザ

1. GitHubアカウントを作る

まず、GitHubのアカウントを作ります。

  1. ブラウザで GitHub を開きます。
  2. Sign up をクリックします。
  3. メールアドレスを入力します。
  4. パスワードを決めます。
  5. ユーザー名を決めます。
  6. 画面の指示にしたがって登録します。

ユーザー名はURLに使われます

GitHubのユーザー名は、あとで公開URLに入ります。

たとえば、ユーザー名が nihongo-teacher の場合、公開URLは次のような形になります。 

https://nihongo-teacher.github.io/サイト名/

2. HTMLを入れる箱を作る

GitHubでは、ファイルを入れる場所のことを リポジトリ と言います。

ここでは、HTMLファイルを入れるための新しいリポジトリを作ります。

  1. GitHubにログインします。
  2. 画面右上の ＋ をクリックします。
  3. New repository をクリックします。
  4. Repository name に nihongo-study-site と入力します。
  5. Public を選びます。
  6. Create repository をクリックします。

Publicを選ぶ理由

インターネットで公開するページなので、 ここでは Public を選びます。

個人情報、学生の名前、メールアドレス、成績などは入れないでください。

3. HTMLファイルを入れる

作ったリポジトリに、HTMLファイルを入れます。

ここでは、パソコンに保存してあるHTMLファイルを、GitHubの画面から入れます。

  1. 作ったリポジトリを開きます。
  2. Add file をクリックします。
  3. Upload files をクリックします。
  4. 公開したいHTMLファイルを選びます。
  5. 必要なCSSファイルや画像ファイルも一緒に入れます。
  6. 画面の下にある Commit changes をクリックします。

入れるファイルの例

学習用HTMLだけを公開する場合は、たとえば次のように入れます。 

nihongo-study-site/
├── index.html
├── study.html
├── css/
│   └── style.css
└── images/
    └── 使っている画像ファイル

トップページとして最初に開きたいHTMLは、 index.html という名前にしておくとわかりやすいです。

ここを間違えやすいです

HTMLファイルだけを入れても、CSSや画像を使っている場合は、 見た目がくずれたり、画像が出なかったりします。

HTMLで使っている css フォルダや images フォルダも、必要なら一緒に入れてください。

4. GitHub Pagesをオンにする

ファイルを入れただけでは、まだWebページとして公開されていない場合があります。

GitHub Pagesをオンにして、インターネットで見られるようにします。

  1. リポジトリの画面を開きます。
  2. 上のメニューから Settings をクリックします。
  3. 左側のメニューから Pages をクリックします。
  4. Build and deployment のところを見ます。
  5. Source がある場合は、 Deploy from a branch を選びます。
  6. Branch で main を選びます。
  7. フォルダは /root を選びます。
  8. Save をクリックします。

公開には少し時間がかかります

設定してすぐには表示されないことがあります。 1〜2分待ってから、もう一度開いてください。

5. 公開URLを開いて確認する

GitHub Pagesの設定ができると、公開URLが表示されます。

URLは、だいたい次のような形になります。 

https://ユーザー名.github.io/nihongo-study-site/

たとえば、ユーザー名が nihongo-teacher の場合は、次のようになります。 

https://nihongo-teacher.github.io/nihongo-study-site/
  1. GitHub Pagesの画面に出たURLをコピーします。
  2. ブラウザの別のタブで開きます。
  3. HTMLページが表示されるか確認します。
  4. 表示できたら、そのURLを学生に共有できます。

公開前に必ず確認すること

学生にURLを送る前に、次の内容を確認してください。

  • 学生の名前やメールアドレスが入っていないか
  • 成績や出席情報などの個人情報が入っていないか
  • リンクを開いたときに、正しいページが出るか
  • スマホでも見やすいか
  • 問題の答えが間違っていないか

GitHubの英語ボタンの意味

GitHubの画面は英語で表示されることがあります。 よく使うボタンだけ覚えておくと作業しやすいです。

英語 意味
Sign up 新しく登録する
Sign in ログインする
New repository 新しいファイル置き場を作る
Add file ファイルを追加する
Upload files パソコンのファイルを入れる
Commit changes 入れたファイルを保存する
Settings 設定
Pages Webページとして公開する設定
Save 保存

うまく表示されないとき

起きていること よくある原因 確認すること
404と表示される 公開設定がまだ終わっていない、またはURLが違う Settings → Pages のURLをもう一度確認する
トップページが出ない index.html がない 最初に開きたいHTMLを index.html にする
見た目がくずれる CSSファイルが入っていない css フォルダもGitHubに入れる
画像が出ない 画像ファイルが入っていない、または場所が違う images フォルダもGitHubに入れる
直したのに古いページが出る 反映に少し時間がかかっている 少し待ってから更新する
大事な注意

公開してよい内容だけを入れる

GitHub Pagesで公開したページは、URLを知っている人が見ることができます。

次のような情報は、公開ページに入れないでください。

  • 学生の名前
  • 学生のメールアドレス
  • 出席率
  • 成績
  • 住所や電話番号
  • 学校内部だけで使う資料

学習用ページには、公開しても問題ない教材内容だけを入れます。 個人情報が入っていないか、公開前に必ず確認してください。
