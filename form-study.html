竹内先生集中講義フォーム学習用

入力フォームの作り方を覚えよう

1. フォームとは

フォームは、Webページでユーザーに情報を入力してもらうための仕組みです。

例えば、名前を入力したり、メールアドレスを入力したり、 アンケートに答えたりするときにフォームを使います。

覚える：
HTMLでフォームを作るときは <form> を使う。

フォームの例

2. フォームの基本形

フォームは <form> の中に、 入力欄やボタンを書いて作ります。 

<form action="送信先" method="post">
  <label for="name">名前</label>
  <input type="text" id="name" name="name">

  <input type="submit" value="送信">
</form>
部分 意味
<form> フォーム全体を表す
action 入力内容の送信先を指定する
method 送信方法を指定する
<label> 入力欄の説明を書く
<input> 入力欄を作る
type="submit" 送信ボタンを作る

3. formタグ

<form> は、フォーム全体を囲むタグです。 入力欄やボタンは、基本的に <form> の中に書きます。 

<form>
  入力欄やボタンを書く
</form>
覚える：
フォーム全体は <form> で囲む。

4. action属性とmethod属性

<form> には、よく action と method を書きます。 

<form action="contact.php" method="post">
  ...
</form>
属性 意味
action フォームの送信先を指定する
method 送信方法を指定する

methodの種類

method 特徴
get 入力内容がURLに表示される。検索フォームなどで使うことがある。
post 入力内容がURLに表示されにくい。お問い合わせフォームなどで使うことが多い。
授業で覚えるポイント：
action は送信先、method は送信方法。

5. inputタグ

<input> は、1行の入力欄やボタンなどを作るタグです。 type 属性の値によって、入力欄の種類が変わります。 

<input type="text" name="username">
属性 意味
type 入力欄の種類を指定する
name 送信するときのデータ名を指定する
id labelと関連付けたり、CSSで指定したりするときに使う
value 初期値やボタンに表示する文字を指定する
placeholder 入力例を薄い文字で表示する

6. よく使うinputのtype

type 意味 例
text 1行のテキスト入力 <input type="text">
email メールアドレス入力 <input type="email">
password パスワード入力 <input type="password">
number 数字入力 <input type="number">
date 日付入力 <input type="date">
radio 1つだけ選ぶ選択肢 <input type="radio">
checkbox 複数選べる選択肢 <input type="checkbox">
submit 送信ボタン <input type="submit">
reset 入力内容をリセットするボタン <input type="reset">

7. テキスト入力欄

名前や住所など、1行の文字を入力する欄は type="text" を使います。 

<label for="name">名前</label>
<input type="text" id="name" name="name">

表示例

覚える：
1行の文字入力は <input type="text">

8. labelタグ

<label> は、入力欄の説明を表すタグです。 for 属性と入力欄の id を同じにすると、 ラベルと入力欄を関連付けることができます。 

<label for="email">メールアドレス</label>
<input type="email" id="email" name="email">
部分 意味
for="email" どの入力欄の説明かを指定する
id="email" 入力欄につける名前のようなもの
ポイント：
label の for と、入力欄の id は同じ名前にする。

9. placeholder属性

placeholder は、入力欄の中に入力例を表示する属性です。 

<input type="text" name="name" placeholder="例：山田太郎">

表示例

覚える：
placeholder は入力例を表示する。

10. メールアドレス入力

メールアドレスを入力する欄は type="email" を使います。 

<label for="mail">メールアドレス</label>
<input type="email" id="mail" name="mail">

表示例

11. パスワード入力

パスワードを入力する欄は type="password" を使います。 入力した文字は、画面上では見えにくく表示されます。 

<label for="password">パスワード</label>
<input type="password" id="password" name="password">

覚える：

14. textareaタグ

長い文章を入力する欄は <textarea> を使います。 感想、自己紹介文、お問い合わせ内容などに使います。 

<label for="message">メッセージ</label>
<textarea id="message" name="message"></textarea>

表示例

覚える：
長い文章の入力は <textarea>

15. selectタグ

プルダウンメニューを作るときは <select> と <option> を使います。 

<label for="country">出身国</label>
<select id="country" name="country">
  <option value="vietnam">ベトナム</option>
  <option value="china">中国</option>
  <option value="nepal">ネパール</option>
  <option value="japan">日本</option>
</select>

表示例

タグ 意味
<select> プルダウンメニュー全体
<option> 選択肢

16. required属性

required をつけると、入力必須の項目になります。 未入力のまま送信しようとすると、ブラウザが注意を表示します。 

<input type="text" name="name" required>

表示例

覚える：
required は入力必須にする属性。

17. 送信ボタンとリセットボタン

フォームを送信するボタンは type="submit"、 入力内容を消すボタンは type="reset" を使います。 

<input type="submit" value="送信">
<input type="reset" value="リセット">

表示例

コード 意味
type="submit" 送信ボタン
type="reset" リセットボタン

18. name属性とvalue属性

フォームでは name と value が大切です。

属性 意味
name 送信するときの項目名
value 送信される値、またはボタンに表示する文字 
<input type="radio" name="gender" value="male"> 男性
<input type="radio" name="gender" value="female"> 女性
ポイント：
name はデータの名前、value は送られる内容。

19. フォームにCSSを当てる

フォームはCSSを使うと、入力しやすく見やすいデザインにできます。 

form {
  background-color: #f8fbff;
  padding: 20px;
  border-radius: 10px;
}

label {
  font-weight: bold;
  display: block;
  margin-top: 10px;
}

input,
textarea,
select {
  width: 100%;
  padding: 8px;
  border: 1px solid #999;
  border-radius: 5px;
}

input[type="submit"] {
  background-color: #27ae60;
  color: white;
  border: none;
  margin-top: 15px;
}
CSS 意味
width: 100%; 入力欄を横幅いっぱいにする
padding 入力欄の内側の余白
border 入力欄の枠線
border-radius 角を丸くする
background-color 背景色を指定する

21. よくある間違い

間違い1：formタグで囲んでいない

悪い例： 
<input type="text" name="name">
<input type="submit" value="送信">

入力欄や送信ボタンは、基本的に <form> の中に書きます。

正しい例： 
<form>
  <input type="text" name="name">
  <input type="submit" value="送信">
</form>

間違い2：labelのforとinputのidが違う

悪い例： 
<label for="user">名前</label>
<input type="text" id="name" name="name">
正しい例： 
<label for="name">名前</label>
<input type="text" id="name" name="name">

間違い3：radioのnameをバラバラにする

ラジオボタンで1つだけ選ばせたい場合は、同じグループの name を同じにします。

悪い例： 
<input type="radio" name="spring" value="spring"> 春
<input type="radio" name="summer" value="summer"> 夏
正しい例： 
<input type="radio" name="season" value="spring"> 春
<input type="radio" name="season" value="summer"> 夏

26. 実践課題

課題：自己紹介サイトにお問い合わせフォームを作ろう

自己紹介サイトで使っている MySiteフォルダ の中に、 フォームを使ったページを作りましょう。

ファイル名は contact.html にします。

このページでは、見た人があなたにメッセージを送るための お問い合わせフォームを作ります。

課題の目的：
<form>、<label>、 <input>、<textarea>、 <select> を使って、 入力フォームを作る練習をします。

保存場所

必ず守ること：
作成した contact.html は、 自己紹介サイトの MySiteフォルダ の中に保存してください。 
MySite
├── index.html
├── profile.html
├── country.html
├── contact.html
└── style.css

作るフォームの内容

  • 名前を入力する欄
  • メールアドレスを入力する欄
  • 出身国を選ぶプルダウンメニュー
  • 好きな内容を選ぶチェックボックス
  • メッセージを書く欄
  • 送信ボタン
  • リセットボタン
  • メインページに戻るリンク
