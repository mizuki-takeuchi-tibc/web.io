HTMLフォーム確認テスト

form・input・label・textarea・selectなどを確認しよう

テストの説明

HTMLフォームに関する確認テストです。
それぞれの問題で、正しい答えを1つ選んでください。

「採点する」ボタンを押すまで、答えは表示されません。

問題1

フォーム全体を表すHTMLタグはどれですか。

正解：<form>
<form> はフォーム全体を囲むタグです。

問題2

1行の文字入力欄を作るときに使うコードはどれですか。

正解：<input type="text">
名前などの1行入力には type="text" を使います。

問題3

長い文章を入力する欄を作るタグはどれですか。

正解：<textarea>
感想やメッセージなど、長い文章の入力には <textarea> を使います。

問題4

入力欄の説明を表すタグはどれですか。

正解：<label>
<label> は入力欄の説明を書くタグです。

問題5

<label> の for 属性と同じ値にするものはどれですか。

正解：入力欄の id
label の for と input の id を同じにすると、ラベルと入力欄が関連付きます。

問題6

メールアドレス入力欄を作るときに使うコードはどれですか。

正解：<input type="email">
メールアドレスの入力欄には type="email" を使います。

問題7

パスワード入力欄を作るときに使うコードはどれですか。

正解：<input type="password">
パスワード入力では、入力した文字が画面上で見えにくく表示されます。

問題8

複数の選択肢から1つだけ選ばせたいときに使うものはどれですか。

正解：ラジオボタン
ラジオボタンは、複数の選択肢から1つだけ選ぶときに使います。

問題9

複数の選択肢を選べるようにしたいときに使うものはどれですか。

正解：チェックボックス
チェックボックスは、複数選択できる項目に使います。

問題10

プルダウンメニューを作るタグはどれですか。

正解：<select>
プルダウンメニューは <select> で作ります。

問題11

<select> の中の選択肢を作るタグはどれですか。

正解：<option>
<select> の中に <option> を書いて選択肢を作ります。

問題12

フォームの送信ボタンを作るコードはどれですか。

正解：<input type="submit">
type="submit" はフォームを送信するボタンです。

問題13

入力内容をリセットするボタンを作るコードはどれですか。

正解：<input type="reset">
type="reset" は、フォームの入力内容を元に戻すボタンです。

問題14

入力必須にする属性はどれですか。

正解：required
required をつけると、その入力欄は必須項目になります。

問題15

入力欄の中に薄い文字で入力例を表示する属性はどれですか。

正解：placeholder
placeholder は入力例を表示する属性です。

問題16

action 属性の意味として正しいものはどれですか。

正解：フォームの送信先を指定する
action は、フォームの入力内容をどこに送るかを指定します。

問題17

method 属性の意味として正しいものはどれですか。

正解：フォームの送信方法を指定する
method は、get や post などの送信方法を指定します。

問題18

name 属性の意味として正しいものはどれですか。

正解：送信するときの項目名を指定する
name は、フォーム送信時のデータの項目名になります。

問題19

ラジオボタンで1つだけ選べるようにするために大切なことはどれですか。

正解：同じグループの name を同じにする
ラジオボタンは、同じ name の中から1つだけ選べます。

問題20

次のコードの説明として正しいものはどれですか。

<label for="name">名前</label>
<input type="text" id="name" name="username">
正解：名前を入力する1行の入力欄を作っている
type="text" なので、1行のテキスト入力欄です。
