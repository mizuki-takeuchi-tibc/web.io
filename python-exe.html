Pythonアプリをexeファイルにする

作成したPythonアプリを、ダブルクリックで開ける .exeファイル に変換します。

このページでやること

前のページで作った席替えアプリのPythonコードを、 メモ帳などのテキストエディタに貼り付けて seat_app.py というファイル名で保存します。

そのあと、PyInstallerを使って、 ダブルクリックで起動できる seat_app.exe を作ります。

1
コードを保存

ChatGPTが作ったコードを seat_app.py として保存します。

2
cmdを開く

ドキュメントフォルダでコマンドプロンプトを開きます。

3
PyInstallerを入れる

exeファイルを作るための道具をインストールします。

4
exeを作る

コマンドを実行してPythonファイルをexeに変換します。

最初に知っておくこと

Pythonで作ったアプリは、通常はPythonが入っているPCで実行します。 しかし、.exeファイル にすると、 ダブルクリックで起動できるアプリの形にできます。

言葉 意味
.py Pythonのコードを書いたファイルです。例：seat_app.py
.exe Windowsでダブルクリックして起動できる実行ファイルです。
PyInstaller Pythonファイルをexeファイルに変換するための道具です。
コマンドプロンプト 文字で命令を入力して、PCに作業させる画面です。

今回は研修用PCで作業します

研修用PCには、Pythonがすでに入っている前提で進めます。 そのため、このページではPythonのダウンロードやインストールは扱いません。

自分のPCで同じ作業をする場合は、先にPythonのインストールが必要になることがあります。

STEP 1：Pythonコードを .py ファイルとして保存する

まず、ChatGPTが作ったPythonコードを seat_app.py という名前で保存します。

.py ファイルは、特別なソフトで作る必要はありません。 中身はテキストなので、メモ帳などのテキストエディタに貼り付けて保存できます。

  1. ChatGPTが作ったPythonコードを、最初から最後まで全部コピーします。
  2. メモ帳などのテキストエディタを開きます。
  3. コピーしたコードを全部貼り付けます。
  4. ファイル → 名前を付けて保存 をクリックします。
  5. 保存場所として ドキュメント を選びます。
  6. ファイル名を seat_app.py にします。
  7. 保存します。

.pyファイルはテキストファイルです

Pythonのコードは、見た目は普通の文章のようなテキストです。 そのため、メモ帳などに貼り付けて保存できます。

ただし、ファイル名の最後は .py にします。 これにより、Pythonのプログラムファイルとして扱えるようになります。

メモ帳で保存するときの注意

ファイル名は seat_app.py にします。

ただし、Windowsの設定によっては、実際には seat_app.py.txt のように保存されてしまうことがあります。 その場合は、Pythonファイルとして正しく扱えません。

メモ帳で保存するときに「ファイルの種類」を選べる場合は、 すべてのファイル を選んでから seat_app.py として保存してください。

STEP 2：ドキュメントフォルダでコマンドプロンプトを開く

次に、seat_app.py を保存した ドキュメントフォルダでコマンドプロンプトを開きます。

  1. エクスプローラーで ドキュメント フォルダを開きます。
  2. seat_app.py があることを確認します。
  3. 画面上部のアドレスバーをクリックします。
  4. そこに cmd と入力します。
  5. Enterキーを押します。

すると、ドキュメントフォルダの場所で コマンドプロンプトが開きます。

この方法が簡単です

コマンドでフォルダを移動する必要がありません。 seat_app.py があるフォルダで そのままコマンドプロンプトを開けます。

場所が違うとエラーになります

コマンドプロンプトを開いた場所に seat_app.py がないと、 PyInstallerがファイルを見つけられません。

その場合は、もう一度ドキュメントフォルダを開き、 アドレスバーに cmd と入力して開き直してください。

STEP 3：PyInstallerをインストールする

Pythonファイルをexeファイルに変換するために、 PyInstaller をインストールします。

コマンドプロンプトに、次のコマンドを入力してEnterキーを押します。 

python -m pip install pyinstaller

もし上のコマンドでうまくいかない場合は、次のコマンドを試します。 

py -m pip install pyinstaller

少し時間がかかることがあります

インストールには少し時間がかかる場合があります。 画面にたくさん文字が出ても、あわてずに終わるまで待ちます。

STEP 4：exeファイルを作る

PyInstallerを使って、seat_app.py から seat_app.exe を作ります。

コマンドプロンプトに、次のコマンドを入力してEnterキーを押します。 

python -m PyInstaller --onefile --windowed seat_app.py

もし上のコマンドでうまくいかない場合は、次のコマンドを試します。 

py -m PyInstaller --onefile --windowed seat_app.py
部分 意味
PyInstaller Pythonファイルをexeファイルに変換する道具です。
--onefile 1つのexeファイルにまとめます。
--windowed アプリ起動時に黒いコマンド画面を出さないようにします。
seat_app.py 変換したいPythonファイル名です。

完了まで待ちます

exeファイルの作成には少し時間がかかります。 途中で画面を閉じないでください。

STEP 5：できあがったexeファイルを確認する

変換が終わると、ドキュメントフォルダの中に いくつか新しいフォルダやファイルができます。

完成したexeファイルは、次のフォルダの中にあります。 

dist

dist フォルダの中に、 seat_app.exe ができています。

  1. ドキュメントフォルダを開きます。
  2. dist フォルダを開きます。
  3. seat_app.exe をダブルクリックします。
  4. 席替えアプリの画面が表示されれば成功です。

配布するとき

--onefile を使っているので、 基本的には dist フォルダの中にある seat_app.exe を渡せば使えます。

ただし、今回のアプリはGoogleスプレッドシートを読み込むため、 使うPCがインターネットにつながっている必要があります。

作成後にできるファイル

PyInstallerを実行すると、ドキュメントフォルダの中に 次のようなファイルやフォルダができます。 

Documents
├─ seat_app.py
├─ seat_app.spec
├─ build
└─ dist
   └─ seat_app.exe
名前 説明
seat_app.py 元のPythonコードです。
seat_app.spec PyInstallerが作る設定ファイルです。
build exe作成の途中で使われる作業用フォルダです。
dist 完成したexeファイルが入るフォルダです。
seat_app.exe 完成したアプリです。これをダブルクリックして使います。

buildフォルダなどは何？

build フォルダや seat_app.spec は、exeファイルを作る途中で作成されるものです。

実際に使う完成品は、基本的には dist フォルダの中の seat_app.exe です。

よくあるつまずき

困ったこと 原因 対処
python が認識されない Pythonのコマンド名が違う場合があります。 py を使って実行してみます。
No module named PyInstaller と出る PyInstallerがまだ入っていません。 python -m pip install pyinstaller または py -m pip install pyinstaller を実行します。
seat_app.py が見つからない コマンドプロンプトを開いた場所に seat_app.py がありません。 ドキュメントフォルダを開き、アドレスバーに cmd と入力して、そこでコマンドプロンプトを開き直します。 また、ファイル名が seat_app.py.txt になっていないか確認します。
seat_app.py.txt になっている メモ帳で保存するときに、テキスト文書として保存されている可能性があります。 保存するときに「ファイルの種類」を すべてのファイル にして、 seat_app.py という名前で保存し直します。
exeを開いてもすぐ閉じる 元のPythonコードにエラーがある、または必要な情報が読み込めていない可能性があります。 前のページで作ったPythonコードを見直します。 コードを途中までしかコピーしていない場合もあるので、最初から最後まで貼り付けたか確認します。
Windowsが警告を出す 自作exeファイルなので、Windowsが確認を求めることがあります。 自分で作ったファイルであることを確認して実行します。
exeファイルが大きい Python本体や必要な部品も一緒に入るためです。 異常ではありません。数十MB以上になることがあります。
完成

できあがり

これで、Pythonを直接開かなくても、 seat_app.exe をダブルクリックして 席替えアプリを起動できるようになります。
