Pythonアプリをexeファイルにする

作成したPythonアプリを、ダブルクリックで開ける .exeファイル に変換します。

このページでやること

前のページで作った席替えアプリのPythonコードを seat_app.py というファイル名で保存し、 PyInstallerを使って seat_app.exe を作ります。

1
Pythonコードを保存

ChatGPTが作ったコードを seat_app.py として保存します。

2
PyInstallerを入れる

exeファイルを作るための道具をインストールします。

3
exeファイルを作る

コマンドを実行してアプリを変換します。

4
ダブルクリックで確認

できあがったexeファイルを開いて確認します。

最初に確認すること

今回は研修用PCで作業します

研修用PCには、Pythonがすでに入っている前提で進めます。 そのため、Pythonのダウンロードやインストールは基本的に行いません。

自分のPCで同じ作業をする場合は、Pythonが入っていない可能性があります。 その場合は、先にPythonのインストールが必要です。

確認するもの 内容
Python Pythonコードを動かすために必要です。
seat_app.py 前のページで作った席替えアプリのPythonファイルです。
PyInstaller Pythonファイルをexeファイルに変換するための道具です。

STEP 1：Pythonコードを .py ファイルとして保存する

まず、ChatGPTが作ったPythonコードを seat_app.py という名前で保存します。

  1. Pythonを開きます。
  2. File → New File をクリックします。
  3. 新しい編集画面が開きます。
  4. ChatGPTが作ったPythonコードを、最初から最後まで全部貼り付けます。
  5. File → Save As をクリックします。
  6. 保存場所として ドキュメント を選びます。
  7. ファイル名を seat_app.py にします。
  8. 保存 をクリックします。

ファイル名に注意

ファイル名は seat_app.py にします。 最後が .py になっていることを確認してください。

seat_app.py.txt のようになると、 Pythonファイルとして正しく扱えないことがあります。

STEP 2：保存したファイルを一度実行して確認する

exeファイルにする前に、まず seat_app.py が正しく動くか確認します。

  1. Pythonの編集画面で seat_app.py を開きます。
  2. Run → Run Module をクリックします。
  3. 席替えアプリの画面が表示されるか確認します。

ここで動かない場合

この時点でエラーが出る場合は、まだexeファイルにはしません。 先にPythonコードが正しく動く状態に直します。

STEP 3：コマンドプロンプトを開く

PyInstallerは、コマンドを入力して使います。 ここではWindowsのコマンドプロンプトを使います。

  1. Windowsの検索欄をクリックします。
  2. cmd と入力します。
  3. コマンドプロンプト を開きます。

黒い画面、または文字だけの画面が開けばOKです。

STEP 4：ドキュメントフォルダに移動する

先ほど seat_app.py をドキュメントに保存したので、 コマンドプロンプトでもドキュメントフォルダに移動します。

以下のコマンドを入力して、Enterキーを押します。

cd %USERPROFILE%\Documents

意味

cd は「フォルダを移動する」という意味です。 このコマンドで、自分のドキュメントフォルダに移動します。

STEP 5：PyInstallerをインストールする

次に、Pythonファイルをexeファイルに変換するための PyInstaller をインストールします。

以下のコマンドを入力して、Enterキーを押します。

python -m pip install pyinstaller

もしこのコマンドでうまくいかない場合は、次のコマンドを試します。 

py -m pip install pyinstaller

少し時間がかかることがあります

インストールには少し時間がかかる場合があります。 画面にたくさん文字が出ても、あわてずに終わるまで待ちます。

STEP 6：exeファイルを作る

PyInstallerを使って、seat_app.py から seat_app.exe を作ります。

以下のコマンドを入力して、Enterキーを押します。

python -m PyInstaller --onefile --windowed seat_app.py

もしこのコマンドでうまくいかない場合は、次のコマンドを試します。 

py -m PyInstaller --onefile --windowed seat_app.py
部分 意味
PyInstaller Pythonファイルをexeファイルに変換する道具です。
--onefile 1つのexeファイルにまとめます。
--windowed アプリ起動時に黒いコマンド画面を出さないようにします。
seat_app.py 変換したいPythonファイル名です。

完了まで待ちます

exeファイルの作成には少し時間がかかります。 途中で画面を閉じないでください。

STEP 7：できあがったexeファイルを確認する

変換が終わると、ドキュメントフォルダの中に いくつか新しいフォルダやファイルができます。

主に見る場所は、次のフォルダです。

dist

dist フォルダの中に、 seat_app.exe ができています。

  1. ドキュメントフォルダを開きます。
  2. dist フォルダを開きます。
  3. seat_app.exe をダブルクリックします。
  4. 席替えアプリの画面が表示されれば成功です。

配布するとき

--onefile を使っているので、 基本的には dist フォルダの中にある seat_app.exe を渡せば使えます。

ただし、今回のアプリはGoogleスプレッドシートを読み込むため、 使うPCがインターネットにつながっている必要があります。

作成後にできるファイル

PyInstallerを実行すると、次のようなファイルやフォルダができます。 

Documents
├─ seat_app.py
├─ seat_app.spec
├─ build
└─ dist
   └─ seat_app.exe
名前 説明
seat_app.py 元のPythonコードです。
seat_app.spec PyInstallerが作る設定ファイルです。
build exe作成の途中で使われる作業用フォルダです。
dist 完成したexeファイルが入るフォルダです。
seat_app.exe 完成したアプリです。これをダブルクリックして使います。

よくあるつまずき

困ったこと 原因 対処
python が認識されない Pythonのコマンド名が違う場合があります。 py を使って実行してみます。
No module named PyInstaller と出る PyInstallerがまだ入っていません。 python -m pip install pyinstaller を実行します。
seat_app.py が見つからない コマンドプロンプトの場所が違います。 cd %USERPROFILE%\Documents でドキュメントに移動します。
exeを開いてもすぐ閉じる 元のPythonコードにエラーがある可能性があります。 先にPythonで seat_app.py を実行して確認します。
Windowsが警告を出す 自作exeファイルなので、Windowsが確認を求めることがあります。 自分で作ったファイルであることを確認して実行します。
exeファイルが大きい Python本体や必要な部品も一緒に入るためです。 異常ではありません。数十MB以上になることがあります。
完成

できあがり

これで、Pythonを直接開かなくても、 seat_app.exe をダブルクリックして 席替えアプリを起動できるようになります。
