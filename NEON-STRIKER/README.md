# NEON STRIKER

既存の「シューティングゲーム」とは別に制作した、オリジナルの縦スクロールシューティングです。画像・音声の外部ダウンロードやオンライン接続は不要です。背景、機体、敵、ボス、エフェクトをCanvasで描画し、効果音はWeb Audioで合成します。

## 遊び方

- WASD / 矢印キー：移動
- Shift：精密移動
- 射撃：自動
- 1 / 2 / 3：パルス・ランス・スプレッドに切替
- Space：ボム（敵弾消去・範囲攻撃・一時無敵）
- P / Esc：一時停止・再開
- マウスを押したままドラッグ：移動

3宙域で敵編隊とボスを突破します。敵が落とすPアイテムで武器を強化し、緑の＋で耐久値を回復します。ボス撃破後には、火力・修復・シールドの強化を選べます。CASUALでは敵弾が遅くなり、敵編隊の出現間隔が広がります。

## Windows EXE

作成済みの配布フォルダーでは `NEON-STRIKER.exe` を実行してください。EXEだけを移動せず、フォルダーごと保存してください。コード署名はされていません。Windows実機での起動は未確認です。

ソースから作成する場合はWindows 10/11 x64のPowerShellで、このREADMEのあるフォルダーから次を実行します。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Build-Windows.ps1
```

このプロセス内だけスクリプト実行を許可します。PC全体の実行ポリシーは変更しません。公式Electron 44.9.3をダウンロードし、公式のSHA256と照合した後に `dist` 以下へ新しい配布フォルダーを作成します。Node.jsやPythonのインストールは不要です。ビルド時のみインターネット接続が必要です。PowerShellスクリプトのWindows実機実行は未確認です。

## ブラウザーで試す

`app/index.html` をブラウザーで開いてください。外部素材やサーバーには依存しません。ブラウザーの管理ポリシーでfile URLがブロックされる場合は `python3 -m http.server 8000 --directory app` でローカル配信できます。
