竹内先生集中講義TABLE学習用

表を作るためのHTMLタグとCSSを覚えよう

1. テーブルとは

テーブルは、データを行と列で整理して表示するために使います。 例えば、時間割、成績表、料金表、商品一覧などを作るときに便利です。

覚える：
HTMLで表を作るときは <table> を使う。

2. テーブルで使う基本タグ

テーブルでよく使うHTMLタグ
タグ 意味
<table> 表全体を表す
<tr> 表の1行を表す
<th> 見出しセルを表す
<td> 普通のデータセルを表す
<caption> 表のタイトルを表す
覚える：
table は表全体、tr は行、th は見出し、td はデータ。

3. 基本のテーブル

次のように書くと、簡単な表を作ることができます。

<table>
  <tr>
    <th>名前</th>
    <th>年齢</th>
    <th>出身地</th>
  </tr>
  <tr>
    <td>田中</td>
    <td>18</td>
    <td>東京</td>
  </tr>
  <tr>
    <td>佐藤</td>
    <td>19</td>
    <td>大阪</td>
  </tr>
</table>

表示例

名前 年齢 出身地
田中 18 東京
佐藤 19 大阪

4. table・tr・th・tdの関係

テーブルは、次のような構造になっています。

<table>
  <tr>
    <th>見出し1</th>
    <th>見出し2</th>
  </tr>
  <tr>
    <td>データ1</td>
    <td>データ2</td>
  </tr>
</table>
部分 説明
<table> 表全体を囲む
<tr> 1行ごとに書く
<th> 見出しのセルに使う
<td> 普通のデータのセルに使う

5. captionで表のタイトルをつける

<caption> を使うと、表にタイトルを付けることができます。 表の内容が何を表しているのか分かりやすくなります。 

<table>
  <caption>成績表</caption>
  <tr>
    <th>科目</th>
    <th>点数</th>
  </tr>
  <tr>
    <td>国語</td>
    <td>80</td>
  </tr>
</table>

表示例

成績表
科目 点数
国語 80
数学 90

6. thead・tbody・tfoot

表の構造を分かりやすくするために、 <thead>、<tbody>、<tfoot> を使うことがあります。

タグ 意味
<thead> 表のヘッダー部分
<tbody> 表の本体部分
<tfoot> 表のフッター部分、合計など 
<table>
  <thead>
    <tr>
      <th>商品</th>
      <th>価格</th>
    </tr>
  </thead>

  <tbody>
    <tr>
      <td>りんご</td>
      <td>100円</td>
    </tr>
    <tr>
      <td>みかん</td>
      <td>80円</td>
    </tr>
  </tbody>

  <tfoot>
    <tr>
      <th>合計</th>
      <td>180円</td>
    </tr>
  </tfoot>
</table>

表示例

商品 価格
りんご 100円
みかん 80円
合計 180円

7. 列を結合する colspan

横方向、つまり列を結合したいときは colspan 属性を使います。 

<table>
  <tr>
    <th colspan="2">プロフィール</th>
  </tr>
  <tr>
    <td>名前</td>
    <td>田中</td>
  </tr>
</table>

表示例

プロフィール
名前 田中
年齢 18
覚える：
colspan="2" は、横に2つ分のセルを結合する。

8. 行を結合する rowspan

縦方向、つまり行を結合したいときは rowspan 属性を使います。 

<table>
  <tr>
    <th>曜日</th>
    <th>科目</th>
  </tr>
  <tr>
    <td rowspan="2">月曜日</td>
    <td>国語</td>
  </tr>
  <tr>
    <td>数学</td>
  </tr>
</table>

表示例

曜日 科目
月曜日 国語
数学
火曜日 英語
覚える：
rowspan="2" は、縦に2つ分のセルを結合する。

9. テーブルにCSSを当てる

HTMLだけでも表は作れますが、見た目を整えるにはCSSを使います。 

table {
  width: 100%;
  border-collapse: collapse;
}

th, td {
  border: 1px solid #000;
  padding: 10px;
}

th {
  background-color: #e3efff;
}
CSS 意味
width: 100%; 表の幅を親要素いっぱいにする
border-collapse: collapse; セル同士の線を重ねて、すっきり表示する
border 枠線をつける
padding セルの内側の余白をつける
background-color 背景色をつける
ポイント：
テーブルの枠線は、HTMLの border 属性ではなく、CSSの border で指定するのが基本です。

10. よく使うテーブル用CSS

目的 CSS 例
表の線を1本にする border-collapse border-collapse: collapse;
枠線をつける border border: 1px solid #000;
内側の余白 padding padding: 10px;
文字を中央揃え text-align text-align: center;
背景色 background-color background-color: #eee;
幅 width width: 100%;

11. thとtdの違い

タグ 意味 使う場所
<th> 見出しセル 項目名、列名、行名など
<td> データセル 実際のデータ
覚える：
th は見出し、td は普通のデータ。

12. よくある間違い

間違い1：trを書かずにtdを書く

悪い例： 
<table>
  <td>名前</td>
  <td>年齢</td>
</table>

<td> は必ず <tr> の中に書きます。

正しい例： 
<table>
  <tr>
    <td>名前</td>
    <td>年齢</td>
  </tr>
</table>

間違い2：見出しにもtdを使ってしまう

表の見出しには、できるだけ <th> を使います。

間違い3：colspanとrowspanを逆に覚える

属性 意味
colspan 横方向、列を結合する
rowspan 縦方向、行を結合する

13. 必ず覚える重要コード

<table>
  <tr>
    <th>見出し1</th>
    <th>見出し2</th>
  </tr>
  <tr>
    <td>データ1</td>
    <td>データ2</td>
  </tr>
</table>
table {
  border-collapse: collapse;
}

th, td {
  border: 1px solid #000;
  padding: 10px;
}

14. テスト直前チェックリスト

  • 表全体は <table>
  • 1行は <tr>
  • 見出しセルは <th>
  • 普通のデータセルは <td>
  • 表のタイトルは <caption>
  • 表のヘッダー部分は <thead>
  • 表の本体部分は <tbody>
  • 表のフッター部分は <tfoot>
  • 横にセルを結合するのは colspan
  • 縦にセルを結合するのは rowspan
  • 枠線はCSSの border で指定する
  • セルの内側の余白は padding
  • セルの線をすっきりさせるには border-collapse: collapse;

15. 暗記用まとめ

table は表全体
tr は1行
th は見出し
td はデータ

caption は表のタイトル

colspan は横に結合
rowspan は縦に結合

border は枠線
padding は内側の余白
border-collapse: collapse; は線を重ねる

17. 実践課題

課題：母国と日本の違いを表でまとめよう

自己紹介サイトで使っている MySiteフォルダ の中に、 テーブルを使ったページを作りましょう。

ファイル名は country.html にします。

テーマは「母国と日本の違い」です。 自分の母国と日本を比べて、違うところや似ているところを HTMLの表で分かりやすくまとめてください。

課題の目的：
<table>、<tr>、 <th>、<td> を使って、 情報を表として整理する練習をします。

保存場所

必ず守ること：
作成した country.html は、 自己紹介サイトの MySiteフォルダ の中に保存してください。 
MySite
├── index.html
├── profile.html
├── country.html
└── style.css

作る表の例

母国と日本の違い
項目 母国 日本
あいさつ シンチャオ こんにちは
食べ物 フォー 寿司、ラーメン
交通 バイクが多い 電車が多い
季節 暑い季節が長い 四季がある
学校生活 朝から勉強します 授業の時間が決まっています

書く内容の例

表の項目は、次の中から選んでもいいです。

  • あいさつ

必ず使うタグ

  • <table>：表全体
  • <tr>：表の1行
  • <th>：見出しセル

できれば使うタグ・属性
